# Super Wheel

Super Wheel is a customizable Wheel of Names-style random name picker built as a simple, interactive web application.

## Features

* Add and remove names
* Interactive spinning wheel
* Smooth acceleration and realistic deceleration
* Custom spin duration and rotations
* Custom animation/easing controls
* Precise winner selection
* Winner popup with Close and Remove options
* Spin history
* Custom wheel colors and appearance
* Customizable wheel border thickness and colors
* Border glow and lighting effects
* Custom LED/light effects around the wheel
* Customizable title and branding
* Settings panel for advanced options
* Responsive design for desktop and mobile
* Customizable sound effects
* Visual controls for spin animation

## Secondary / Backup Version

## Purpose

Super Wheel is designed for quickly picking random names in classrooms, games, activities, or other situations where a simple and customizable random name picker is useful.
